# 🏥 Disease Risk Prediction System

A machine learning project that predicts potential disease risk based on input health-related features. The project demonstrates data preprocessing, model training, evaluation, and prediction using supervised machine learning techniques.

## 🚀 Overview

The system analyzes patient-related input features and uses machine learning classification algorithms to estimate disease risk.

The project focuses on applying a complete machine learning workflow:

**Data → Preprocessing → Model Training → Evaluation → Prediction**

## ✨ Features

* Data preprocessing and cleaning
* Feature preparation for machine learning
* Handling class imbalance using oversampling
* Disease risk classification
* Model comparison
* Performance evaluation
* Prediction on new input data

## 🤖 Machine Learning Models

The project experiments with:

* Random Forest Classifier
* Support Vector Machine (SVM)

### Model Performance

| Model         | Accuracy |
| ------------- | -------: |
| Random Forest |   68.98% |
| SVM           |   60.53% |
